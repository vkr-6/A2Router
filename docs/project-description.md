# Project description

GitHub About description:

> Portable audio routing for Windows and Linux, with multi-output playback, channel mapping, delay compensation, VB-CABLE integration and a compact Qt interface.

Long description:

A2Router (Advanced Audio Router) is a portable desktop utility for managing audio
routes between physical and virtual devices. It combines a compact PySide6
workspace with a native C++20 WASAPI engine on Windows and PipeWire routing on
Linux. Users can manage concurrent routes, duplicate audio across outputs,
configure supported channel mappings and gains, adjust supported software delays,
inspect endpoint formats, and save routing profiles. Windows integration supports
existing VB-CABLE endpoints and explicit vendor driver management. Device identity,
feedback protection and truthful backend status take priority over visual effects.
Acoustic calibration is planned; production readiness and sample-perfect
synchronization are not claimed.
