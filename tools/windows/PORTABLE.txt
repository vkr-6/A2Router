A2Router — Advanced Audio Router (Windows x64)

Extract the complete folder and launch a2router.exe. This is the only A2Router
application executable; the vendor folder retains original VB-Audio utilities. Python, Qt and the native WASAPI bridge are bundled.
There is no separate console version and no app installer.

Audio Routing is the main workspace. Use the compact top navigation and menus.
Routing Configuration contains synchronization; Mixer has observed endpoint peaks
and master volume/mute. Unsupported readings show N/A. Stop Routing preserves
enabled route choices. Emergency Mute requests the same serialized transport stop.

Virtual devices lists an existing VB-CABLE without reinstalling it. Add VB-CABLE
installs the original vendor driver only when explicitly clicked. Administrator
approval is required; active endpoints are refreshed automatically. Restart
requirements are reported rather than forcing a reboot.

Select a playback or recording endpoint and Scan formats. Choose a supported
channel count, bit depth and sample rate, then Apply format. Stop managed routes
using that endpoint first. For multichannel sources, configure the recording
endpoint too. Source/destination channel editors follow the active formats.
Rename in Windows changes the real endpoint name, requesting elevation when
required, and retains the stable ID used by routes. Windows Sound remains a
fallback. Windows format-policy compatibility needs target-machine verification.

Keep vendor/vb-cable and vendor/install-vbcable.ps1 beside the app. The base
package is one shared cable. Send apps to its playback side and route its
recording side in A2Router. Remove driver requires explicit confirmation and
removal of dependent routes; this affects all apps and may require a restart.
Exit and delete the portable folder to remove A2Router itself.

Optional channel routing provides remapping, duplication, summing and gain.
Unmapped outputs are silent; source omissions require confirmation. Mixed peaks
are clipped to +/-1. The integrated delay section shows native buffering/drift metrics and
supported delay controls. No bit-perfect or measured acoustic-sync claim.

Settings: %APPDATA%\a2router. Closing hides/minimizes; Exit stops Windows routing.
