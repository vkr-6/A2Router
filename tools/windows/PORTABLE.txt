A2Router — Advanced Audio Router (Windows x64)

Extract this entire folder and launch a2router.exe. Use a2router-cli.exe diagnostics
for observations. Python, Qt and the native WASAPI bridge are bundled.
No app installer is required. Starting A2Router does not install a driver.

Virtual devices: enter an A2Router display name and click Create output to install
or reuse the single VB-CABLE. Installation requests administrator approval,
verifies PnP and refreshes devices. An active endpoint can be used immediately;
restart requirements are reported when pending or no endpoint becomes available.
Configure channels / Windows name opens Windows Sound for actual endpoint
settings. The name field in A2Router is a saved local alias only.

Keep vendor/vb-cable and vendor/install-vbcable.ps1 beside the app. Send apps to
CABLE Input, then route CABLE Output to speakers/headphones. For driver removal,
remove dependent routes and explicitly choose Remove driver in Virtual devices.
Removal affects all apps and may need a restart. To remove A2Router itself, exit
and delete the portable folder. Check Windows defaults after installing drivers.

Optional Custom channel routing supports remapping, duplication, summing and gain.
Unmapped outputs are silent. Mixed peaks are clipped to ±1; reduce gain to avoid
clipping. Synchronization reports available buffering, rate correction and errors.
Live delays use native buffers; restart fallback is explicitly opt-in.
No measured acoustic synchronization or bit-perfect hardware claim is made.

Settings: %APPDATA%\a2router. Closing hides/minimizes; Exit stops Windows routing.
