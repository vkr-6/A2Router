A2Router — Advanced Audio Router (Windows x64)

Launch a2router.exe or use a2router-cli.exe diagnostics. The portable application
includes Python/Qt and the native WASAPI bridge. Use the setup EXE to install
VB-CABLE automatically when absent. The vendor payload is also retained under
vendor/vb-cable/. Installing a driver needs administrator approval and a restart.
The driver is not installed on ordinary application startup.

VB-CABLE is donationware by VB-Audio Software (https://www.vb-cable.com/).
Donations and licenses are welcome: https://vb-audio.com/Services/licensing.htm.
The original vendor license and files remain unchanged. This is one shared
cable, not an arbitrary number of named devices. Send apps to CABLE Input and
route CABLE Output to speakers/headphones. A2Router uninstall offers to remove the shared driver with a restart.
Pre-existing drivers default to keeping; silent removal needs /REMOVEVBCABLE=1. Check Windows defaults after installing any audio driver.

Synchronization keeps edits until Apply/Discard. Live delay changes use the
native FIFO when supported; source restart requires the explicit option.
Automatic drift compensation is not measured acoustic synchronization.
Refresh updates rows in place and preserves selection and unapplied edits.

Configuration: %APPDATA%\a2router. Closing hides/minimizes the app. Exit controller
stops Windows routing. No bit-perfect or hardware-playback claim is made.
